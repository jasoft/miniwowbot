## 三、澄清：「无免费按钮 → 标记完成」是正确语义

> **2026-09-18 18:10 大王拍板更正**：本报告初版把 `auto_dungeon_core.py:145-149`
> 判为「把失败写成成功的代码缺陷」，**这个判断是错的**。
> 没有「免费」按钮意味着当天已经打过了，就应该写库。

相关代码（`auto_dungeon_core.py:146-151`，`auto_dungeon_runner.py:213-220` 是同款）：

```python
if not battle_started:
    logger.warning("⚠️ 无免费按钮，标记为已完成")
    db.mark_dungeon_completed(zone_name, dungeon_name)
```

**语义是对的**：没有「免费」按钮 = 该副本今天的免费次数已被（本角色的某条流程）消耗 =
**今天已经打过了**。写库反映的是「这个副本今天不需要再打了」，不是「战斗失败了」。

因此这段代码**保持原样**，并已在两处加上注释，防止将来再被当成 bug 修掉。

它带来的唯一真实副作用是：**免费次数耗尽这件事在日志里只以 warning 出现，不够醒目**。
但那属于可观测性，不是逻辑错误。
