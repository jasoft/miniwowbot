## 任务与区域推进

运行入口：

```powershell
uv run airtest run levelup.air --device Android://127.0.0.1:5037/127.0.0.1:5565
```

入口复用 Airtest 命令行已经连接的设备。直接运行 `levelup.py` 时，才读取
`MINIWOW_EMULATOR` 或默认设备。

游戏包含主线、多段支线和地下城任务。完成任务后可能自动弹出后续任务，
此时根据 OCR 中的“完成”和“接受任务”按钮处理，不能连续盲点同一坐标。

“领取任务”打开指定大陆的任务清单，“切换区域”改变该清单所属的大陆。
它与野外地点（如星光之森）和具体地下城不是同一层级。

领取流程先回到列表顶部，扫描支线和地下城任务；已经接受的任务仍可能出现在
清单中，应跳过它并继续检查其他条目。本区仍有执行中的任务时等待推进。
只有完整扫描到列表末尾、没有剩余任务时，才根据大陆顺序切换。

切区使用任务清单标题确定当前大陆，使用菜单中的“等级 + 大陆名”定位下一项，
并重新读取清单标题确认成功。切换后立即继续领取新区任务。
菜单尚未加载或 OCR 失败时保留当前区域并重试；亡灵之地是当前菜单末区，
没有下一大陆，不能继续点击菜单下方。

流程实现分别位于 `task_regions.py`（区域解析）和 `task_workflow.py`（页面流程）。
操作期间暂停工作流 OCR 扫描，避免共享 OCR 实例被同时调用。

回归测试：

```powershell
uv run pytest levelup.air/tests/test_task_workflow.py -m "not integration"
```
